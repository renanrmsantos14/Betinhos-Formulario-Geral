Regras De Uso

Contrato visual e técnico para futuras alterações.

não quebrar app.js
Faça
  • Use tokens existentes.
  • Preserve IDs, `data-*` e handlers.
  • Use `.field` para campos comuns.
  • Use custom select compartilhado.
  • Teste popup, overflow, z-index e mobile.
  • Escreva pt-BR com acentos.
Não faça
  • Não crie landing page ou hero.
  • Não crie card decorativo.
  • Não espalhe azul sem função.
  • Não troque IDs por estética.
  • Não duplique dropdown custom.
  • Não use fonte mono como acento visual.
